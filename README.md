# تحليل بيانات إصابات العمل الخطيرة (OSHA)

مشروع تحليل بيانات باستخدام Python وPandas، يستهدف استكشاف سجل إصابات العمل الخطيرة في الولايات المتحدة، في مجال السلامة والصحة المهنية.

## 📊 مصدر البيانات

**Severely Injured Workers** — Kaggle
🔗 https://www.kaggle.com/datasets/jboysen/injured-workers

سجل رسمي لحوالي 21,578 حالة إصابة عمل خطيرة (2015-2017)، تم توثيقها ضمن بلاغات OSHA الإجبارية (بتر، دخول مستشفى، فقدان وعي...).

## 🛠️ الأدوات المستخدمة

- Python
- Pandas

## 📌 خطوات التحليل

1. **قراءة واستكشاف البيانات:** تحميل الملف وفحص الأعمدة (26 عمود، 21,578 صف) باستخدام `df.info()` و`df.describe()`
2. **معالجة التواريخ:** تحويل عمود `EventDate` واستخراج الشهر والسنة لمعرفة توزيع الحوادث الزمني
3. **تحليل وصفي:** استخراج أكثر أنواع الإصابات تكرارًا (`NatureTitle`)، وأكثر الولايات تضررًا (`State`)، وأكثر أجزاء الجسم إصابةً
4. **تصنيف مبني على منطق برمجي:** بناء دالة تصنيف باستخدام Loops وDictionaries وConditionals لتقسيم الإصابات إلى "خطيرة" و"متوسطة" بناءً على كلمات مفتاحية في وصف الإصابة

## 🔍 أهم النتائج

- أكثر نوعين إصابة تكرارًا هما **Fractures** (6,018 حالة) و**Amputations** (5,833 حالة)، ويمثلان معًا أكثر من نصف الحالات المسجلة
- التصنيف الأولي بكلمات مفتاحية محدودة أظهر أن ~57% من الحالات "خطيرة"، لكن مراجعة أكثر 15 نوع إصابة كشفت عن أنواع خطيرة أخرى (Crushing, Intracranial injuries, Electrical burns) لم تكن القائمة الأولى تغطيها، مما أدى إلى تعديل معايير التصنيف

## 💡 خلاصة

التصنيف بالاعتماد على كلمات مفتاحية فقط تقريبي بطبيعته، ويحتاج لمراجعة مستمرة على البيانات الفعلية قبل الاعتماد على نتائجه.

مشروع تعليمي في تحليل البيانات بمستوى مبتدئ إلى متوسط، بالتركيز على أساسيات Python وPandas في مجال السلامة والصحة المهنية.
